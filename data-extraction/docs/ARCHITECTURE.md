# 架构说明

## 数据流
```text
文件选择 → 格式识别 → DataFrame → values/percent 自动提取 → 预览/筛选 → 本地导出
```

## 模块
- `app.py`：窗口布局、文件读取、格式解析、筛选、复制和导出。
- `i18n.py`：中文 / English 文本资源。
- `i18n_runtime.py`：运行时语言刷新与关于弹窗。
- GitHub Actions：Windows 测试、单文件构建、启动检查和 Release。

## 设计原则
- 导入即提取，降低操作成本。
- 原始行优先保留，避免解析失败导致数据丢失。
- 高级筛选为可选能力，不阻塞主流程。
- 数据只在本地处理。
