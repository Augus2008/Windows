# 故障排查

## Windows 阻止运行
确认从本仓库 Release 下载并核对 SHA-256。未签名 EXE 可能触发 SmartScreen。

## 提示缺少 Python DLL
不要单独复制旧的 onedir 版 EXE。请下载当前 Release 中约 33MB 的单文件版。

## 未提取到 values / percent
确认同一行中同时包含两个字段，例如：
```text
values:4184mV percent:100%
```
支持 `:` 和 `=`。若键名不同，请提交脱敏样本和需求 Issue。

## 中文乱码
程序会自动尝试常见编码。若仍乱码，请确认原始文件编码，并附最小脱敏样本。

## Excel 无法读取
确认文件未加密、扩展名与实际格式一致，且文件未损坏。

## 大文件界面短暂无响应
解析为同步操作。请等待完成，避免重复点击。建议先复制一份较小样本验证规则。

## 清空全部数据
点击红色按钮并确认。它只清除程序内存中的当前数据，不删除磁盘上的原始文件。

## 报告问题
使用 Bug Issue 模板并提供版本、Windows 版本、格式、步骤和脱敏样本。
