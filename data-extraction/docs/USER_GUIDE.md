# 用户指南

## 系统要求
- Windows 10 或 Windows 11，64 位。
- 推荐至少 4GB 内存。
- 大文件处理速度取决于文件大小和磁盘性能。

## 快速开始
1. 从正式 Release 下载 `DataExtractionTool.exe`。
2. 双击运行。若 SmartScreen 提示未知发布者，请先核对来源与 SHA-256。
3. 点击“导入文件（可多选）”，可用 Ctrl / Shift 选择多个文件。
4. 选择文件后等待解析完成。
5. 单文件沿用自动提取；多文件保留合并后的全部行列，可统一筛选。
6. 点击“导出当前结果”，先选择 Excel、CSV 或 TXT，再选择保存位置。取消任一步都不会写出文件。

## 自动提取
程序匹配不区分大小写的 `values:` / `values=` 与 `percent:` / `percent=`。一行必须同时包含两个字段，才进入默认结果。

示例：
```text
NPMA/I : values:4184mV percent:100%
```
结果：
```text
values   percent
4184mV   100%
```

## 高级筛选
支持包含、不包含、等于、不等于、开头、结尾、大于、小于、为空和非空。多个条件可选择 AND 或 OR。

## 表格操作
- 单击选择行；Ctrl / Shift 可多选。
- `Ctrl+C` 复制所选行。
- 右键可复制单元格或所选行。
- “列操作”可选择需要显示及导出的列。

## 清空数据
点击红色“清空全部数据”并确认后，会清除文件、原始数据、结果、筛选条件和表格内容；当前语言不会改变。

## 语言与关于
左侧底部的“关于 / About”按钮菜单提供使用指南、语言切换和软件信息。使用指南说明操作流程及限制；语言可切换中文和 English；软件信息显示当前版本、构建日期与版权。

## 隐私
所有解析和导出在本机完成。分享样本或截图前，请自行脱敏。

## 批量筛选
按列名对齐，缺列留空，增加来源文件列；Excel 每个文件只读首表。导入成功会替换旧数据；读取失败或取消则保留旧数据。筛选后导出一个结果文件。批量模式重新自动提取会保留来源列，恢复原始数据可回到完整合并表。

## 对账报告（0.14.0 源码）
导入后点击“对账报告”检查每个文件的状态、读取工作表/有意跳过工作表、解析行数、当前保留及排除行数。空文件仍列出0行。来源记录列是解析记录序号，不能当作物理文本行号。
筛选后再次查看报告，核对各文件合计；阶段记录注明从原始数据重算还是从当前结果处理，避免把恢复/重新筛选带回的数据当作异常增加。
导出成功提示仅在全部内容回读一致后出现。回读包括全部结果，不只预览前500行。Excel使用文本单元格保留长编号和前导零，但不保留原Excel类型、公式或样式。
报告可单独保存为JSON，包含最近导出对应的阶段与文件校验摘要；它不会随每次导出自动上传。界面中尚未应用的筛选条件与已经执行的阶段需分开看。报告含本机路径及筛选内容，分享前脱敏。

## 全量图表（当前源码，尚未构建 EXE）
图表以点击生成图表时的当前提取/筛选结果快照为准，包含全部记录，按原顺序绘制，不抽样、不截断、不按横轴去重；表格的500行预览上限不限制图表。若主界面之后改变结果，请重新打开图表以取得新的结果快照。
正常的有限数值均纳入绘制；缺失、非数值、不兼容单位或无效横轴不能伪造坐标，记录仍保留，并显示不可绘制统计与原因。折线在无效坐标处断开，不跨缺失记录连线。未勾选的系列是用户明确排除，不是后台抽样。
PNG/PDF/SVG 与预览使用同一全量数据。图表 Excel 的 Chart Data 包含全部记录及所选横轴/系列；未选其他业务列仍请使用主界面数据导出。
数据越多，解析、画布和导出耗时及内存占用可能越高；不会为了提速偷偷改为抽样。超出 Excel 工作表行数容量将明确报错，不输出截断结果。图像像素有限，多个数据点视觉上可能重叠，不等于抽点。
已交付0.15.6 EXE仍使用旧图表机制；只有后续构建才能获得本次功能。

自定义未知单位只更改标签，不代表数值已换算；已知不同物理维度的单位不能强行互换，会计入不可绘制原因。

图表Excel新增的 `Record idx (0-based)` 是当前结果快照中从0开始的位置，用于核对图表数据顺序；它不是原文件物理行号，也不是每文件的“来源记录”。如需文件级追溯，请同时保留主界面导出和对账报告。很长的整数横轴编号无法用浮点数无损表示时，应保留完整文本标签，不能为了图表把编号改值。

本构建纳入全部当前结果绘图，移除5000点限制和抽样；PNG/PDF/SVG及图表Excel同步全量，空值断线并透明统计。长编号横轴保留完整文本；单位框清空不绕过维度校验。大数据可能更慢、更占内存；独立Windows CI构建，不发布Release。前文“未构建”章节是历史开发记录，不代表本构建仍使用抽样。
