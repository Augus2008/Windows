# 浅色数据工作台：第一版界面预览

本轮保留 CustomTkinter + ttk，重排布局，不替换解析、对账与导出核心。当前源码用于视觉评审；已交付0.14.0 EXE不会因此改变，尚未生成含新UI的安装包。

## 设计原则
- 数据表格优先：浅灰蓝背景与白色工作面板，减少饱和颜色和大面积深色。
- 输入、处理、输出分区：左侧文件与工作表，主区筛选与表格，右上导出。
- 单一主色：导出为蓝色主要操作，次要动作中性，危险操作只用少量红色强调。
- 真实统计：文件数与读取行数来自实际导入记录，筛选结果来自当前模型；空文件也列入文件清单。
- 明确状态：未执行导出校验不能展示“验证通过”；输入框中修改但未应用的条件不能冒充当前结果条件。
- 保留中英文切换、单文件Excel工作表切换、复制、列选择、对账和图表入口。

## 截图来源
预览截图是远端 Xvfb 中实际运行的 Tk 应用，通过 Pillow ImageGrab 截取真实像素，并非HTML示意图。模拟数据独立存放，未使用用户业务文件；Linux字体/缩放不等同于Windows原生渲染。

## 验收边界
需复跑现有批量/对账/校验导出测试和UI测试，检查默认1360×820与最小1080×680下主要控件可达。桌面系统高DPI和Windows原生窗口仍需后续构建验证。

### 0.15.1：筛选控件事件
修复原生菜单不会向主窗口冒泡鼠标释放事件而导致提示延迟的问题。列、运算符、逻辑按钮独立选择回调只刷新待应用提示，不修改result或audit。test_filter_events覆盖中英文菜单分派及应用前后的数据状态。

### 标题栏、帮助和统计排版调整（未构建）
只在系统标题栏保留工具名称与表格＋漏斗图标；移除侧栏重复品牌，数据源上移。三项统计各自居中。右上帮助纳入中英文详细指南、语言、关于。主窗口、帮助、关于、导入进度、列选择、对账、图表采用统一多尺寸图标；Windows系统提示符号仍保留含义。代码已接入ICO构建参数，但须另行构建新EXE才影响已交付版本。

### 导出格式弹窗与顶部原生菜单（源码预览）
原生系统标题栏不改造。帮助位于紧贴标题栏下方的菜单栏，不再占据导出旁的按钮位置。侧栏数据源及格式说明居中，格式文案缩小为一至两行；移除主区顶部重复导入提示。
用户点击导出按钮后先选择Excel、CSV或TXT，再通过保存对话框决定路径；取消格式选择不调用保存对话框，取消保存不写出文件。数据校验、输入文件保护和对账记录仍由既有导出流程负责。
此轮尚未在Windows上构建验证，Linux实际截图用于布局和交互评审；原生菜单栏显示风格由系统决定。已交付0.15.2 EXE不受影响。

### 当前工作树：工具栏紧凑化（未构建）
帮助入口移至侧栏底部，保留指南、语言和关于；去掉原生顶端菜单。对账与图表居中于结果预览标题行，导出按钮位于该行右侧。移除顶部导出空栏，统计与筛选整体上移，将回收高度用于表格。此前布局章节是历史记录，以本段为当前预览。
